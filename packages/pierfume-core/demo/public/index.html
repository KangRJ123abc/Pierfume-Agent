原料库速览

填写 brief 后点击「生成配方」。

Agent 将只使用原料库中的原料,创建配方后强制经过 formula_lint 与 ifra_check 两道工具链校验;本页展示的合规结论由本地 CLI 独立复验,不采信模型自述。

配方 YAML

纯本地执行:formula-lint(结构/引用/总量)+ ifra-check(IFRA 合规),不调用模型。

粘贴配方或载入示例后点击「本地校验」。
